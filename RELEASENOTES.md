# StoryTeller X 2.0.0

This major release modernizes StoryTeller X for Foundry VTT 13 and later.

## Highlights

- Migrated the Story Sheet to Foundry's Application V2 API.
- Added per-journal theme selection while retaining a module-wide default theme.
- Added Newspaper, Ship Captain's Log, and Starship Captain's Log themes alongside the original Book theme.
- Added theme-specific typography, page navigation, page-turn presentation, and computer-style sounds for the Starship theme.
- Improved page, index, content-panel, title, navigation, and edit-button alignment across all themes.
- Fixed the sheet configuration dialog so selecting Story Sheet immediately shows the correct theme choices.
- Added a Default journal theme option that inherits the module-wide theme setting.
- Reduced and cleaned up theme assets, including removal of unused generated newspaper images and bundling the locally licensed Oxanium font.

## Compatibility

- Minimum Foundry VTT version: 13
- Verified Foundry VTT version: 14
